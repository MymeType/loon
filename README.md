# Loon

Lisp for a more rusty era

## Q&A

### Is this an implementation of an existing Lisp dialect?

No. Much like Clojure and Lisp Flavored Erlang were made from scratch for the JVM and the OTP platforms respectively, Loon has been made in-house specifically for the Rust ecosystem.

### Why another Lisp dialect?

I am a die-hard fan of the Lisp syntax and have tried various dialects and their respective implementations out there, but none of their various offerings of features seemed to fully scratch any itches I had when it came to development of any personal projects of mine. At the same time, I had been distantly admiring the Rust programming language and its compendium of various features such as its renowned memory safety and blazing fast speed, but my biggest turn-off was its very particular syntax compared to other languages I used in the past, so I figured the best way for me to start making use of the language was to make my own dialect built specifically for the Rust ecosystem, just to make my development experience easier in the long term.
